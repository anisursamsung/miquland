# Miquland
Miquland is a dynamic tiling Wayland Compositor build with wlroots along with a suite of apps build with custom made toolkit "miqutoolkit".
-Apps are expected to run independently without Miquland in any Wayland compositor if miqutoolkit is installed. We might later incoporate miqutoolkit into the apps themeselves, thus apps will run completely independently.
- If you want to know funcitonalities, better have a look at assets/miquland.conf you will get the idea.
